# fishify

Site da Fishify, peixaria de Peniche que entrega peixe fresco em casa.

Next.js 16 + React 19 + Tailwind v4. Sem backend: as encomendas abrem uma
conversa de WhatsApp já escrita.

```bash
npm install
npm run dev -- --port 3310
```

O contexto todo do projeto, incluindo as decisões de assets e o que falta
confirmar com o cliente, está em [`docs/CONTEXTO.md`](docs/CONTEXTO.md).
